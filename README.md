# GrowthList

Pick a skill, get an honest, curated set of YouTube creators worth
watching for it — with a four-week plan so watching turns into practice.

Static site: plain HTML/CSS/vanilla JS (ES modules), no framework, no
build step, no backend. See `PLAN.md` for the phased build plan and
`CLAUDE.md` for the data schema and project rules.

Full README (local dev, how to add a creator/category, how to
regenerate data, how the Netlify form works) is written in Phase 6, once
the site and data pipeline exist.
